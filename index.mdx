## Products

| Product | Delivery | Use it for |
|---|---|---|
| [RPC](/rpc/overview) | JSON-RPC 2.0 over HTTP | Reads, history, sending transactions, digital assets |
| [Yellowstone gRPC](/yellowstone/overview) | gRPC (Yellowstone Geyser) | Filtered real-time streams of accounts, transactions and slots |
| [Preplay Shreds](/preplay/overview) | gRPC (Yellowstone `SubscribeDeshred`) | Every transaction a leader produces, as soon as its shreds arrive |
| [Price Feeds](/price-feeds) | Feed to your server | Price updates from every swap and oracle update |
| [SodaStream](/sodastream) (coming soon) | Shreds pushed to your IP and port | Raw shreds for validators and trading infrastructure |

## Example code

Complete, runnable clients in Rust, TypeScript and Go are in [`sodae-io/sodae-docs/examples`](https://github.com/sodae-io/sodae-docs/tree/main/examples). Each one reconnects with backoff, answers keepalive pings and prints the error code when the server refuses a stream.

```bash
git clone https://github.com/sodae-io/sodae-docs
```
